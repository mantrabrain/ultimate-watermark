Bundled Fonts — License Information
====================================

The Ultimate Watermark plugin ships three TrueType fonts so that text
watermarks render reliably on hosts whose system font directories are
empty (shared/minimal Linux hosts, stripped Docker images, etc.).

All three fonts are licensed under the SIL Open Font License v1.1,
which permits redistribution as part of any software bundle.
